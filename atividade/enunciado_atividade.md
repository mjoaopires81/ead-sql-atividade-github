# Atividade: Introdução ao SQL com GitHub

## Objetivo
- Importar a base de dados a partir do ficheiro `dados/base_dados.sql`;
- Criar tabelas e inserir registos;
- Executar consultas SQL básicas (SELECT, WHERE, ORDER BY, etc.);
- Registar o trabalho e as versões no GitHub.

## Tarefas

1. Importa o ficheiro `dados/base_dados.sql` para o teu simulador SQL ou XAMPP.
2. Confirma se as tabelas foram criadas corretamente.
3. No ficheiro `trabalho_aluno/resolucao.sql`, escreve:
   - os comandos SQL para:
     - criação das tabelas;
     - inserção dos registos;
     - consultas pedidas (serão especificadas pela professora em aula ou no Classroom).
4. Faz commits regulares à medida que fores avançando:
   - por exemplo: `create tables`, `insert data`, `first queries`, etc.
5. No final, preenche o ficheiro `trabalho_aluno/reflexao_media.md` com a tua reflexão sobre:
   - que media mais te ajudou a aprender (GitHub, vídeos, W3Schools, IA, etc.);
   - principais dificuldades e como as ultrapassaste.

## Dica
- Podes usar vídeos tutoriais, W3Schools, simuladores SQL e IA (com uso ético) como apoio.
- O foco é perceber o raciocínio e o processo, não apenas o resultado final.
